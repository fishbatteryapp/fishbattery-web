Getting started

Fishbattery is a modern Minecraft launcher focused on fast setup, clean UI, and consistent results. This page explains the basics (instances, mod loaders, mods, and syncing) so you can get running quickly.

Create an instance

An instance is an isolated Minecraft setup with its own game version, loader, mods, and settings. Creating separate instances keeps modpacks clean and prevents conflicts.

  • Pick a Minecraft version
  • Select a mod loader (Fabric / NeoForge)
  • Name your instance (e.g. “FPS”, “SMP”, “RLCraft”)

Install mods (Modrinth)

The easiest workflow is: install only a few mods first, launch once, then expand. That makes it obvious which mod caused an issue if something breaks.

  • Open your instance
  • Browse/search mods
  • Install and launch

Recommended performance baseline

If your goal is “smooth FPS with minimal effort”, start with a lightweight performance stack and add visuals later.

  • Sodium – rendering performance
  • Lithium – game logic optimization
  • FerriteCore – memory usage reduction

Cloud sync

When you’re logged in, Fishbattery can sync launcher configuration across devices so your setup feels the same everywhere. If something looks out of date, check your connection and re-open the launcher to trigger a refresh.

Troubleshooting

If a modded instance won’t launch, the fastest fix is usually to remove the last added mods and try again. For more common issues, see Help & FAQ.
