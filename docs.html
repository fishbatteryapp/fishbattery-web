Getting Started

Fishbattery is a modern Minecraft launcher built for performance, simplicity, and flexibility. It allows you to install mods, manage instances, and sync your setup across devices.

Installing Mods

You can install mods directly through the launcher using Modrinth. Simply create an instance, open it, and browse available mods.

  • Create a new instance
  • Select Fabric or NeoForge
  • Browse and install mods

Performance Optimization

Fishbattery is designed for performance. For best results:

  • Use Sodium for rendering
  • Use Lithium for game logic optimization
  • Limit heavy shader usage

Cloud Sync

Your launcher settings, instances, and configurations can sync across devices when logged in. This ensures a consistent experience everywhere.

Customization

You can customize:

  • Themes (dark, ocean, OLED, etc.)
  • Accent colors
  • Background images
  • UI layout and styling
