Help & FAQ

Launcher won't start

Make sure your system meets the requirements and that Java is installed. Try restarting your computer and reinstalling the launcher if needed.

Mods not working

Ensure you're using the correct mod loader (Fabric or NeoForge). Some mods are not compatible with each other.

Account issues

Try logging out and back in. If issues persist, clear your local data or contact support.

Cloud sync not updating

Make sure you're connected to the internet and logged in. Sync happens automatically, but can take a few seconds.
